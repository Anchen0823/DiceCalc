# DiceCalc

博德之门 3 风格的 d20 检定概率计算器。使用原生 HTML、CSS 与 JavaScript 实现，支持优势/劣势、多个固定加值和骰子加值，结果随输入实时更新。

## 简介

普通模式投掷 `1d20`；优势取 `2d20` 的较大值，劣势取较小值。选定的 d20 结果为 1 时必败，为 20 时必胜，其余情况比较 `d20 + 全部加值 >= DC`。

## 使用说明

1. 用浏览器打开项目根目录下的 **`index.html`** 即可使用（无需服务器）。
2. **检定难度 DC**：输入目标值（1–99），例如 15 表示需要 ≥15 才成功。
3. **优势与劣势**：最多各添加一个；二者同时存在时按普通模式计算。
4. **加值（可选）**：添加多个固定加值或骰子加值，固定加值支持负数；各项可以删除。
5. 页面实时显示成功率、大成功、大失败，以及普通成功和普通失败的占比。

## 规则简述

- **1** → 大失败，必定失败  
- **20** → 大成功，必定成功  
- **2–19** → 骰面 + 加值 ≥ DC 则成功，否则失败  

骰子加值通过离散概率分布卷积计算，结果不是随机模拟的估计值。自然 1/20 的概率会随优势或劣势改变，并非所有模式下均为 5%。此工具实现页面列出的检定规则，其他游戏机制需单独考虑。

## 手动核对示例

在不添加任何加值、DC 为 15 时：

| 模式 | 成功率 | 大成功 | 大失败 |
| --- | --- | --- | --- |
| 普通 | 30% | 5% | 5% |
| 优势 | 51% | 9.75% | 0.25% |
| 劣势 | 9% | 0.25% | 9.75% |
